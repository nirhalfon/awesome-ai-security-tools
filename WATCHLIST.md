# Watchlist

Interesting projects that are not ready for the main awesome list yet. We usually move a project into `data/sections.json` once it has a clear license, enough adoption or maintenance signal, and factual metadata that can be verified without guessing.

## Candidates

- [Redcells](https://github.com/awdemos/redcell) — public-beta automated adversarial testing platform for owned or controlled LLMs. Watch because the repository is very new, has no stars yet, and currently has no clear root license file.
- [Signato](https://github.com/Signato-ai/signato-integrations) — commercial-open confidentiality chamber integrations for Claude Code. Watch because the repository is very new, has no stars yet, and the core engine is proprietary while docs and examples are MIT.
- [Agent Trust](https://github.com/Rain-ouroboros/agent-trust) — advisory receipt library for AI-agent prompts, actions, scopes, and tool descriptors. Watch because the repository is very new, has no stars yet, and the current PR wording overstates runtime enforcement and packaging status.
- [Skarn](https://github.com/skarn-security/skarn-action) — GitHub Action wrapper that scans AI coding-assistant session logs for leaked credentials and attack patterns, then emits redacted SARIF and risk output. Watch because the repository is very new and currently has no stars; the public repo is an MIT Action wrapper, while the scanner engine is a proprietary EULA binary that requires a license token.
- [Purser](https://github.com/purser-io/purser) — static security scanner for ML model artifacts across 18+ formats (pickle/PyTorch/Keras/GGUF/ONNX/safetensors) with a data-exfiltration engine, trust_remote_code AST analysis, a country-of-origin/publisher/format policy engine, signed provenance, and CI + Kubernetes admission enforcement. Watch because the repository is very new and currently has low single-digit stars; it ships a clear Apache-2.0 license, is installable (PyPI, signed GHCR images, Helm chart), and is actively maintained.
- [ARIA](https://github.com/sidevworks/aria-sec) — source-available AI security-operations cockpit with governed autonomy, AI-SPM connectors, local-model support, and audit controls. Watch because the repository is one day old with no stars, the author describes it as active solo development with demo-grade parts, and BSL-1.1 requires a commercial production license until its 2030-07-26 GPL conversion.
- [gate.cat](https://github.com/BGMLAI/gate.cat) — deterministic, fail-closed deny-list that vetoes an AI coding agent's irreversible shell commands (`rm -rf`, disk wipe, prod-DB drop, secret exfiltration) before they run, via pre-execution hooks for Claude Code, Codex, and Cursor. Watch because the repository is very new and currently has low single-digit stars; it ships a clear Apache-2.0 license, is installable (PyPI, `pip install gate.cat`), publishes its own false-block measurement in the repo, and is actively maintained.
